# Change Log

All notable changes to the "context-copier" extension will be documented in this file.

## [1.0.0]

- Initial release of **Context Copier**.
- Copy active file content with `Ctrl+Alt+C` / `Cmd+Alt+C`.
- Copy or combine open tabs directly from tab context menus.
- Copy multi-selected files directly from Explorer context menu.
- Recursively open non-ignored folder contents with Git ignore support.
